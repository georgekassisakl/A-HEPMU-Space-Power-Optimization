> **IEEE AESS Sustainability Hackathon 2026 - Space Systems Track**

---

## 📌 Project Overview

This repository contains the design, hardware control code, and simulation files for a **Space-Hardened Intelligent MPPT (Maximum Power Point Tracking) Power Distribution Module**. The system is optimized to improve energy harvesting and distribution efficiency for satellite and space mission applications under harsh orbital conditions.

---

## 🗂️ Repository Structure

| File / Artifact | Description |
| :--- | :--- |
| `green_bytes_arduino_code.ino` | Arduino source code for intelligent MPPT control and power distribution logic |
| `MPPT_SAT.asc` | LTspice simulation file for the space-grade Maximum Power Point Tracking circuit |
| `Buck-con.asc` | LTspice simulation file for the high-efficiency Buck Converter module |
| `buck_conv.png` | Schematic / Waveform diagram of the Buck Converter |
| `mppt.png` | Circuit diagram / Performance graph of the MPPT system |

---

## ⚙️ Key Technical Features

- **Intelligent MPPT Control:** Embedded tracking algorithm designed to maintain maximum power transfer despite extreme irradiance and temperature variations in space.
- **High-Efficiency DC-DC Conversion:** Customized Buck Converter topology optimized for minimal thermal losses and high energy yield.
- **Radiation-Tolerant System Architecture:** Logic and control strategies optimized for real-time responsiveness and reliability in space systems.

---

## 🛠️ Requirements & Tools Used

- **Hardware/Control:** Arduino IDE (for building and uploading `.ino` code)
- **Simulation:** LTspice (for opening and running `.asc` circuit schematics)
